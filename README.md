# Club 520 Podcast — Official Website

Unofficial website for the **Club 520 Podcast**, hosted by former NBA All-Star **Jeff Teague**, **DJ Wells**, and **B Hen**. Part of The Volume Network.

> No scripts. No filters. Just ball.

---

## Tech Stack

- **Vite** + **React 19**
- **Custom CSS** — no UI framework
- **Google Fonts** — Bebas Neue (display) + Inter (body)
- **YouTube RSS** via rss2json.com for live episode feed

---

## Features

- Branded loading screen with logo animation
- Parallax hero with crew photo
- Basketball custom cursor with trailing glow ring
- Scroll progress bar (orange-to-gold gradient)
- Split-text heading animations on scroll
- YouTube RSS video feed with lightbox player
- Sticky Spotify podcast player bar
- Live/New Episode badge in navbar
- Hosts section with Instagram links
- Notable guests grid by category
- Sponsors & partners grid (Adidas, Boost Mobile, The Volume, DoorDash, GLD, Hard Rock Bet)
- Photo gallery — behind the scenes
- Merch showcase linking to shopclub520.com
- Adidas × Club 520 exclusive collab feature
- Newsletter signup
- Continuous marquee ticker
- Full social footer (YouTube, Instagram, TikTok, X, Facebook, Spotify, Apple Podcasts, Patreon)

---

## Getting Started

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
```
